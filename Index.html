Swiggy Analytics Project

Data Analysis using Python, Pandas and Matplotlib

Project Overview

This project analyzes Swiggy order data to identify customer trends, top-performing restaurants, city-wise performance, ratings, pricing patterns, and monthly order trends.

Analysis Performed

  • Data Cleaning & Preprocessing
  • Missing Value Analysis
  • Duplicate Removal
  • Top 10 Cities Analysis
  • Top 10 Restaurants Analysis
  • Category-wise Analysis
  • Average Price by City
  • Highest Rated Restaurants
  • Monthly Order Trends
  • Rating Distribution
  • Price Distribution

Tools & Technologies

Python
Pandas
NumPy
Matplotlib
Jupyter Notebook
Excel

Key Insights

✔ Identified top-performing cities and restaurants.

✔ Analyzed customer ratings and pricing patterns.

✔ Tracked monthly order trends for business decision-making.
